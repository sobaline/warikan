# 割り勘精算

旅行や飲み会で「誰がいくら立て替えたか」を入力すると、送金回数が少なくなる精算方法を自動で計算するWebアプリです。URLをLINEに貼るだけで、ログインなしでみんなで使えます。

## 主な機能

- 支払いの入力と自動精算（送金回数は「人数−1」回以内）
- 「幹事にまとめる」モード（幹事以外は1回の送金で済む）
- 送金済みチェック
- 外貨対応（自動レートで仮計算し、カード明細の実額に書き換え可能。払った人が損しない）
- メモ・チェックリスト
- ログ（誰がいつ何を変えたか）

## 構成

| 役割 | 使っているもの |
| --- | --- |
| 画面 | HTML / CSS / JavaScript（ビルド不要） |
| データ | Supabase（PostgreSQL） |
| 公開 | Vercel |
| 為替レート | Frankfurter API |

- `settle.js`：精算の計算（端数は立て替えた人以外が持つ）
- `app.js`：画面と操作
- `supabase/schema.sql`：テーブルと、グループごとに見られる範囲を制限する設定（RLS）

ログインがない代わりに、通信のたびにグループID（推測できないランダムな値）を送り、そのグループのデータだけを読み書きできるようにしています。
